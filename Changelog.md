# Changelog

## Revision 1.0.3 (2026-11-23)

- **GW-BASIC Compatible Native BASIC Subsystem (`/BIN/BASIC.BIN`, `user/basic.c`, `user/basic_tokens.h`, `tools/gen_basic_tokens.py`)**:
  - Initiated development of a native, pure user-space GW-BASIC / BASICA compatible interpreter subsystem based on PC-BASIC (GPL v3) token and language specifications.
  - **Phase 1: Interactive REPL, Line Management, Tokenizer, Lister & Basic Execution**:
    - **64 KB Program Memory Segment**: Dynamically allocates a full 64 KB segment via `os_mem_alloc(4096)` managing a linked list of tokenized program lines (`next_offset`, `line_num`, token data, `0x00` delimiter).
    - **GW-BASIC Token Dictionary (`user/basic_tokens.h`)**: Generated from PC-BASIC token tables, supporting all 182 GW-BASIC / BASICA keyword and function tokens (single-byte `0x81..0xF4`, two-byte prefixes `0xFD`, `0xFE`, `0xFF`, and special number tokens).
    - **Fast Case-Insensitive Tokenizer (`basic_tokenize`)**: Tokenizes ASCII input lines with word-boundary checks (preserving identifiers like `PRINTER` vs `PRINT`), string literal preservation, and comment shorthands (`?` for `PRINT`, `'` for `REM`).
    - **Lister (`basic_cmd_list`)**: De-tokenizes bytecode back into formatted ASCII BASIC program listings supporting range arguments (`LIST`, `LIST 10`, `LIST 10-50`, `LIST -30`). Fixed pointer offset in `LIST` argument parsing that previously double-indexed into the token buffer.
    - **Line Insertion / Replacement / Deletion**: Entering a numbered line inserts or replaces lines in sorted numerical order; entering a bare line number deletes the line.
    - **Immediate & Program Execution**: Supports immediate commands (`NEW`, `LIST`, `RUN`, `CLS`, `SYSTEM`) and basic statement execution (`PRINT` with string literals, semicolons, and 14-column commas; `REM`; `END`/`STOP`; `CLS`). Includes non-blocking `Ctrl+C` break handling during program runs.
  - **Phase 2: Variables (%, $), Expression Evaluator & Control Flow (`LET`, `INPUT`, `IF/THEN/ELSE`, `GOTO`, `GOSUB/RETURN`)**:
    - **Variable Subsystem & Symbol Table**: Case-insensitive scalar variables (up to 96 variables) supporting 16-bit signed integer (`%` or default unsuffixed) and dynamic strings (`$`, up to 128 characters). Automatically allocates on first assignment and clears upon `RUN`, `NEW`, or `CLEAR`.
    - **Recursive Descent Expression Evaluator (`basic_eval_expr`)**: Full operator precedence climbing evaluating binary and unary operations:
      - Relational operators (`=`, `<>`, `<`, `>`, `<=`, `>=`) returning standard GW-BASIC truth values (`-1` for TRUE, `0` for FALSE), with string comparisons.
      - Bitwise / logical operators (`AND`, `OR`, `XOR`, `NOT`).
      - Additive & multiplicative arithmetic (`+`, `-`, `*`, `/`, `\`, `MOD`) with zero-division traps and string concatenation (`+`).
      - Integer literals (decimal, `&H` hex, `&O` octal), string literals (`"..."`), and parentheses `( ... )`.
      - Built-in functions: `INKEY$`, `CHR$`, `ASC`, `LEN`, `VAL`, `STR$`, `ABS`, `SGN`, `RND`, `LEFT$`, `RIGHT$`, `MID$`.
    - **Control Flow Statements**:
      - `LET` and implicit variable assignment (e.g. `LET A = 5`, `A = 5`, `NAME$ = "HELLO"`).
      - `INPUT` with optional prompt strings, semicolons/commas (`INPUT "Prompt"; A, B$`), reading comma-delimited input lines.
      - `IF <expr> THEN <statement|linenum> [ELSE <statement|linenum>]` supporting nested IFs, clause skipping, and branch redirection.
      - `GOTO <linenum>` with fast sorted linked-list line lookup.
      - `GOSUB <linenum>` / `RETURN` with a dedicated 32-level return call stack tracking return line and statement position.
  - **Phase 3: Loops (FOR/NEXT, WHILE/WEND), Arrays (DIM, 1D/2D), Data (DATA/READ/RESTORE) & Console (LOCATE, SWAP)**:
    - **FOR ... NEXT Loops**: 16-level nested loop stack tracking loop variable, end target, step increment (`STEP`), and loop body statement position. Supports positive/negative steps, initial out-of-bounds loop skipping, and multi-variable `NEXT I, J`.
    - **WHILE ... WEND Loops**: 16-level nested loop stack evaluating conditions at loop head and branching back upon `WEND`, with forward skipping when false. Fixed return statement pointer to re-execute `TOK_WHILE` on loop iterations rather than skipping into the expression body.
    - **1D & 2D Arrays (`DIM`)**: Up to 32 array descriptors in DS with element data allocated directly in the 60 KB segment heap (`s_basic_seg`). Supports 1D and 2D arrays (`DIM A(10)`, `DIM M(5, 5)`, `DIM NAMES$(20)`), array access and assignment in expressions, bounds checking (`Subscript out of range`), and un-DIM'd default dimension (0..10).
    - **DATA, READ & RESTORE**: Global DATA cursor reading numbers and strings (quoted and unquoted) across program lines, with `Out of DATA` detection and `RESTORE [linenum]`.
    - **Console Utilities**:
      - `LOCATE row, col`: 1-based cursor positioning (`1..25`, `1..80`) via `os_set_cursor()`.
      - `SWAP var1, var2`: Type-safe variable value exchange for integer and string scalar variables.
  - **Phase 4: Program Persistence (SAVE, LOAD, FILES) & Sequential File I/O (OPEN, CLOSE, PRINT#, WRITE#, INPUT#, LINE INPUT#, EOF)**:
    - **GW-BASIC Program Persistence**:
      - `SAVE "filename" [, A]`: Saves program to disk. By default writes standard GW-BASIC tokenized binary `.BAS` format (magic byte `0xFF`, 2-byte line links, 2-byte line numbers, tokenized byte streams, terminated by `0x00, 0x00`). When `, A` is supplied, exports de-tokenized plain ASCII source.
      - `LOAD "filename" [, R]`: Clears current program and variables, then loads from disk. Autodetects binary tokenized format (`0xFF` header) vs ASCII text lines; tokenizes ASCII lines line-by-line upon load. If `, R` is given, immediately executes after loading.
      - `FILES [filespec]`: Catalogs disk files matching pattern (or `*.*`) via `os_dir_entry()`, formatted in standard multi-column display with file size.
    - **Sequential File I/O Subsystem**:
      - Manages up to 4 concurrent file channels (`#1..#4`) with 256-byte streaming I/O buffers.
      - `OPEN mode, #n, "filespec"` and `OPEN "filespec" FOR INPUT/OUTPUT/APPEND AS #n`: Supports Input (`"I"`), Output (`"O"`), and Append (`"A"`) modes with hobbyOS FAT12/FAT16 file syscalls.
      - `CLOSE [#n [, #m ...]]`: Flushes pending buffers and closes specified channels, or all open channels if no arguments specified. Automatic file cleanup on program end (`END`, `STOP`, `NEW`, `RUN`, `SYSTEM`).
      - `PRINT #n, expr...`: Sequential formatted data output to file channel #n with commas, semicolons, and newline control.
      - `WRITE #n, expr...`: GW-BASIC delimited record output with comma separation and quoted string encapsulation.
      - `INPUT #n, var...`: Parses comma-delimited sequential fields from file channel #n into numeric and string variables.
      - `LINE INPUT #n, var$`: Reads an entire line from file channel #n into a string variable.
      - `EOF(n)`: Built-in boolean function returning `-1` (TRUE) when channel #n has reached end-of-file, or `0` (FALSE) otherwise.
  - **Phase 5: Hardware Graphics & Sound (SCREEN, COLOR, PSET, PRESET, LINE, CIRCLE, BEEP, SOUND, PLAY)**:
    - **Screen Modes (`SCREEN`)**:
      - `SCREEN 0`: Text mode (80x25 text via `os_gfx_set_mode(0x03)`).
      - `SCREEN 1`: 320x200 4-color CGA graphics (`os_gfx_set_mode(0x04)`).
      - `SCREEN 2`: 640x200 2-color high-resolution CGA graphics (`os_gfx_set_mode(0x06)`).
      - Automatic text mode restoration on program exit, error, Ctrl+C break, or `SYSTEM`.
    - **Color & Palette Selection (`COLOR`)**:
      - Text mode (`SCREEN 0`): `COLOR [fg] [, [bg] [, [border]]]`.
      - CGA mode (`SCREEN 1`): `COLOR [background] [, [palette]]` supporting Palette 0 (green/red/brown) and Palette 1 (cyan/magenta/white) via `os_gfx_set_palette()`.
      - Screen mode 2: Foreground color selection.
    - **Graphics Primitives**:
      - `CLS`: Clears text screen buffer in Mode 0; clears graphics framebuffer in Modes 1 and 2 (`os_gfx_clear(0)`).
      - `PSET (x, y) [, color]` / `PRESET (x, y) [, color]`: Plots pixel with automatic clipping, defaulting to foreground or background color, and updates graphics coordinate history.
      - `LINE [[(x1, y1)] - (x2, y2)] [, [color] [, [B|BF]]]`: Plots standard line, box outline (`B`), or filled solid box (`BF`) via `os_gfx_line()` and `os_gfx_rect()`, supporting continuation from previous endpoint when `(x1, y1)` is omitted.
      - `CIRCLE (x, y), r [, color]`: Midpoint integer circle algorithm plotting with `os_gfx_putpixel()`.
      - Graphics Text `PRINT`: Dual-mode text renderer allowing `PRINT` and `LOCATE` statements to output seamlessly on graphics screens via 8x8 BIOS ROM font (`os_gfx_text`).
      - `INPUT$(n [, [#]f])`: Reads `n` raw characters from the keyboard without screen echo, or from file channel `#f`.
    - **Sound & Music Subsystem**:
      - Unified Sound Architecture: Tone synthesis is driven exclusively through the hobbyOS Unified Sound Subsystem (`os_sound_opl_write`), routing to the Yamaha YMF262 (OPL3) / YM3812 (OPL2) FM hardware when present, and automatically engaging the kernel's real-time AdLib-to-PC-Speaker emulation engine when no sound card is detected. Features immediate release rate envelopes (`0x0F`), carrier total attenuation muting (`0x43 = 0x3F`), and clean channel shutdown (`os_sound_stop()`) to eliminate residual carrier bleeding or background oscillation.
      - `BEEP`: Standard 800 Hz alert chime for ~150 ms.
      - `SOUND freq, duration`: Emits tone at `freq` Hz (37..32767) for `duration` clock ticks (~18.2 ticks/second) using pure 16-bit timing math.
      - `PLAY "MML..."`: Music Macro Language interpreter supporting note names (`A`..`G`, `#`/`+`/`-`), octaves (`O0`..`O6`, `>`, `<`), note lengths (`L1`..`L64`), tempos (`T32`..`T255`), articulation styles (`MN` normal, `ML` legato, `MS` staccato), and rests (`P1`..`P64`).
  - **Memory Reporting & Unsigned Arithmetic Subsystem (`FRE`, `BASIC_TYPE_UINT`)**:
    - `FRE(x)` and `FRE("")`: Implemented memory reporting function returning the dynamic number of free bytes available in the 64 KB interpreter segment (`61440U - used_heap`, reserving 4,096 bytes for stack and buffer overhead). Dynamically shared between `FRE` and the startup banner so both report an exact, consistent `61440 Bytes free` on a fresh start. Supports numeric dummy arguments `FRE(0)` and string dummy arguments `FRE("")` (which simulates string compaction in accordance with GW-BASIC standards).
    - `BASIC_TYPE_UINT`: Introduced unsigned 16-bit value representation for expressions and variables to seamlessly format and print large memory values (`61440`) without negative signed 16-bit wrap (`-4096`), with support in `PRINT`, `PRINT #`, `WRITE #`, `STR$`, `LET`, and unsigned relational comparisons.
  - **Phase 6: Dual-Path Floating-Point & Math Engine (`user/basic_math.h`, `user/basic.c`)**:
    - **Dual-Path Architecture**: Seamlessly targets Intel 8088 / 8086 processors with hardware Intel 8087 FPU acceleration when present (`os_fpu_present() == 1`), and automatic fallback to a pure 16-bit integer soft-float IEEE-754 32-bit single-precision math engine when no coprocessor is installed.
    - **Freestanding 8086 Assembly Primitives (`user/basic_math.h`)**: Pure freestanding implementation compiled with `-0 -fpi87 -zl` without runtime C library (`wlibc`) dependencies. Eliminates undefined compiler helper references (`__U4M`, `__U4D`, `__I4D`) via hardware 16-bit `mul16` (`mul dx` pragma returning `DX:AX`), binary shift sequences (`(x << 3) + (x << 1)` for decimal multiplication), and `u32_div10`.
    - **Hardware 8087 Inline Assembly Pragmas**: Accelerated 8087 FPU instructions via `#pragma aux`: `fpu_hw_init` (`fninit`), `fpu_hw_add`, `fpu_hw_sub`, `fpu_hw_mul`, `fpu_hw_div`, `fpu_hw_sqr`, `fpu_hw_tan` (`fptan` + `fdivp`), `fpu_hw_atn` (`fpatan`).
    - **Freestanding Software IEEE-754 32-bit Engine**:
      - `soft_from_int`, `soft_from_uint`, `soft_to_int`, `soft_to_uint32`, `basic_float_cmp`.
      - Addition & Subtraction (`soft_add_sub`): Mantissa alignment, sign arbitration, normalization.
      - Multiplication (`soft_mul`): 24x24 mantissa multiply partitioned into 12-bit cross-multiplications using 16-bit hardware `mul16`.
      - Division (`soft_div`): 24-step restoring division with pre-normalization and exact quotient alignment.
      - Square Root (`soft_sqr`): Newton-Raphson iteration seeded with IEEE-754 exponent-halved initial guess (`(a >> 1) + 0x1FC00000UL`) delivering exact single-precision roots in 4 iterations.
    - **Transcendental Functions**:
      - Trigonometric: `SIN` and `COS` via accurate Taylor/minimax polynomial with range reduction mod $2\pi$ and reduction to $[0, \pi/4]$, `TAN` via $\sin/\cos$ (or 8087 `fptan`), and `ATN` via Abramowitz & Stegun range-reduced minimax approximation ($\arctan(x) = \pi/4 + \arctan(\frac{x-1}{x+1})$) delivering $< 6 \times 10^{-5}$ error across all quadrants.
      - Exponential & Logarithmic: `EXP` via Taylor series, `LOG` via argument-reduced $\ln((1+y)/(1-y))$ series, and Power operator `^` (`TOK_CARET`) via $a^b = \exp(b \ln(a))$ with exact integer fast path.
      - Number functions: `INT`, `FIX`, `CINT`, `CSNG`, float `ABS`, float `SGN`, `VAL`, `STR$`.
    - **Interpreter Integration & Bug Fixes**:
      - Unsuffixed variables default to single-precision float (`BASIC_TYPE_FLOAT`) in conformance with GW-BASIC / BASICA.
      - Real literal parsing (decimals and scientific notation `E`/`D`), float array support (`DIM A(10)` with 4-byte float elements).
      - Fixed left-hand operand type clobbering in `eval_mul`, `eval_power`, and `eval_add` where `out_val->type = BASIC_TYPE_FLOAT` was erroneously assigned before converting the left operand (`val_to_float(out_val)`), which had caused integer operands to read as zero in float division (`10 / 4 = 0`) and exponentiation (`2 ^ 10 = 0`).
      - Implemented 32-bit integer float converter `soft_from_uint32` and updated `basic_parse_float_far` so fractional mantissas and divisors are converted with full 32-bit precision, fixing 16-bit truncation that previously distorted floating literals (e.g. `3.141593` becoming `3.6203`).
      - Resolved 8087 FPU lockup on NEC V20 configurations during `ATN`: The Intel 8087 coprocessor specification requires $|ST(1)| < ST(0)$ for `FPATAN`, causing 86Box's NEC V20 FPU emulation to enter an infinite loop on boundary inputs like $ATN(1.0)$. Replaced raw `FPATAN` with the domain-unrestricted range-reduced minimax polynomial (which internally uses 8087 hardware acceleration for all additions, subtractions, multiplications, and divisions), restoring rock-solid stability across both Intel 8088 and NEC V20 hardware.
      - Seamless promotion across mixed integer/float arithmetic in expressions, `/` floating division, `\` integer division, and float relational comparisons.
      - Floating point support in `PRINT`, `PRINT #`, `WRITE #`, `INPUT`, `INPUT #`, `READ`, and `FOR ... NEXT`.
      - **Target Math Verification Test Suite (`/BASIC/MATH.BAS`, `/MATH.BAS`)**: Created comprehensive math verification test suite covering 12 test sections (arithmetic `/`, `\`, `MOD`, `*`, `+`, `-`, powers `2^10`, `3^3`, `9^0.5`, roots `SQR(2)`, `SQR(64)`, transcendentals `SIN`, `COS`, `TAN`, `ATN`, `EXP`, `LOG`, conversions `INT`, `FIX`, `ABS`, `SGN`, float arrays & loops). Verified 100% pass on target Book8088 emulator. Added CLI argument auto-run in `BASIC.BIN` (`basic /math.bas` or `basic math.bas`).
  - **Phase 7: System, Memory & Hardware Access (`DEF SEG`, `PEEK`, `POKE`, `INP`, `OUT`, `TIMER`, `RANDOMIZE`, `RND`)**:
    - **Memory Segment Control (`DEF SEG`)**: Maintained active evaluation segment `s_def_seg` (defaulting to interpreter DS via `get_ds()`). Bare `DEF SEG` restores to DS; `DEF SEG = expr` evaluates segment addresses (e.g. `DEF SEG = &H0040` for BIOS Data Area, `DEF SEG = &HB800` for CGA VRAM, `DEF SEG = &HF000` for ROM BIOS).
    - **Memory Access Functions (`PEEK`, `POKE`)**:
      - `PEEK(addr)`: Reads 8-bit unsigned byte from `MK_FP(s_def_seg, addr)`.
      - `POKE addr, val`: Writes low 8 bits of `val` to `MK_FP(s_def_seg, addr)`.
    - **Hardware Port I/O (`INP`, `OUT`)**:
      - Direct hardware port access via freestanding 8086 `#pragma aux` inline assembly routines `inb(port)` (`in al, dx`) and `outb(port, val)` (`out dx, al`).
      - `INP(port)`: Reads 8-bit value from 16-bit I/O port address.
      - `OUT port, val`: Sends 8-bit byte value to 16-bit I/O port address.
    - **Time Subsystem (`TIMER`)**: Reads 32-bit tick count from BIOS Data Area `0x0040:0x006C` (updated at 18.206482 Hz), scales by `0.05492549` via the floating-point math engine, and returns elapsed seconds since midnight with sub-second precision.
    - **PRNG Subsystem (`RANDOMIZE`, `RND`)**:
      - `RANDOMIZE [seed]`: Re-seeds the 16-bit linear congruential generator seed `s_rnd_seed` (`seed * 214013 + 2531011`). Prompts for user input if no argument is supplied.
      - `RND [(expr)]`: Returns single-precision float strictly in $[0.0, 1.0)$. Negative argument seeds the PRNG; zero returns the previous random float; positive or omitted advances the PRNG sequence.
    - **Expression Grammar Precedence Correction**: Corrected operator precedence order in `basic_eval_expr` by placing relational comparisons (`eval_rel`: `=`, `<>`, `<`, `>`, `<=`, `>=`) at Level 4 between additive arithmetic (`eval_add`) and logical NOT (`eval_not`), AND (`eval_and`), and OR/XOR (`eval_or`), ensuring relational expressions like `R1 = R3 AND R2 = R4` correctly evaluate as `(R1 = R3) AND (R2 = R4)` rather than improperly binding logical `AND` before relational equality.
    - **Far Token Case-Insensitive String Matcher (`basic_strnicmp_far`)**: Implemented segmented far pointer comparison to avoid DS truncation when matching keywords and tokens in `s_basic_seg`.
    - **Target System Verification Suite (`/BASIC/SYS.BAS`, `/SYS.BAS`)**: Comprehensive hardware verification test suite validating BDA video mode read (Mode 3), ROM BIOS machine ID (`0xFE` IBM PC/XT), CGA VRAM poke and restore, live CGA status port `&H3DA` and OPL status `&H388` reads, real-time `TIMER` benchmarking, and PRNG repeatability. Verified 100% passed on target Book8088 emulator.
  - **Phase 8: String Utilities & Formatting (`STRING$`, `SPACE$`, `INSTR`, `HEX$`, `OCT$`, `MID$=`, `PRINT USING`)**:
    - **String Generation Functions**:
      - `STRING$(n, char_code_or_str)` (`TOK_STRING` `0x00D6`): Repeats a character $n$ times ($0 \le n \le 128$), accepting either an ASCII integer code or the first character of a string expression.
      - `SPACE$(n)` (`TOK_SPACE` `0xFF98`): Generates a string containing $n$ space characters.
    - **Base Conversion Functions**:
      - `HEX$(n)` (`TOK_HEX` `0xFF9A`): Converts integer $n$ into an uppercase hexadecimal string representation without leading zeros.
      - `OCT$(n)` (`TOK_OCT` `0xFF99`): Converts integer $n$ into an octal string representation without leading zeros.
    - **Substring Search Function (`INSTR`)**:
      - `INSTR([start,] str1, str2)` (`TOK_INSTR` `0x00D8`): Searches for substring `str2` in `str1` starting at 1-based index `start` (defaults to 1), returning 1-based offset where found, or 0 if not found.
    - **In-Place String Mutation Statement (`MID$=`)**:
      - `MID$(var$, start [, len]) = expr$`: Replaces characters in-place within a string variable or string array element without altering the target's total allocated length, stopping at replacement length, string boundary, or target end. Supports `LET MID$(...) = ...`.
    - **Formatted Output Engine (`PRINT USING`, `PRINT #n, USING`)**:
      - Full implementation of GW-BASIC formatted output supporting console (`PRINT USING`) and file channels (`PRINT #n, USING`).
      - String templates: `!` (first character only), `&` (variable length full string), `\   \` (fixed width $2 + n$ with space padding).
      - Numeric templates: `#` (digit position), `.` (decimal point with half-to-even rounding), `+` (leading/trailing forced sign), `-` (trailing negative sign), `$$` (floating dollar sign), `**` (asterisk fill), `**$` (combined asterisk fill and floating dollar sign), `,` (thousands separator every 3 digits before decimal), and `%` (field overflow indicator).
      - Literal escaping: Underline `_` escapes the following character as a literal text character; format string automatically wraps across multiple arguments and handles trailing format literals.
      - Freestanding arithmetic: Formatter operates using 16-bit integer and soft-float scaling without invoking Watcom runtime library division helpers (`__U4D`/`__I4D`).
    - **Target String Verification Suite (`/BASIC/STR.BAS`, `/STR.BAS`)**: Comprehensive test suite covering all 6 functional areas (STRING$, SPACE$, HEX$, OCT$, INSTR, MID$=, PRINT USING, and PRINT # USING). Verified 100% passed on target Book8088 emulator.
  - **Phase 9: Structured Error Handling (`ON ERROR GOTO`, `RESUME`, `ERR`, `ERL`, `ERROR`, Computed `ON...GOTO/GOSUB`)**:
    - **Error Trapping Engine (`ON ERROR GOTO`)**:
      - `ON ERROR GOTO <linenum>`: Activates runtime error trapping redirecting control flow to the specified line number upon any runtime error (division by zero, overflow, subscript out of range, syntax error, undefined line, type mismatch, etc.).
      - `ON ERROR GOTO 0`: When executed outside an error handler, disables error trapping. When executed inside an active error handler, disables trapping and immediately re-raises the active error as an untrapped fatal error at `s_erl` in accordance with GW-BASIC standards.
      - Error variables `ERR` (`TOK_ERR` `0x00D5`) returning the error code (1..55) and `ERL` (`TOK_ERL` `0x00D4`) returning the line number where the error occurred.
    - **Resume & Statement Recovery (`RESUME`)**:
      - `RESUME` / `RESUME 0`: Clears error handling state and retries the exact faulting statement after variable or state correction.
      - `RESUME NEXT`: Clears error handling state and resumes execution at the statement immediately following the faulting statement on the same line (separated by `:`), or advances to the beginning of the subsequent line if the error occurred on the final statement of a line. Implemented statement boundary scanning (`basic_scan_stmt_boundary`) skipping quoted strings and comments (`REM`, `'`).
      - `RESUME <linenum>`: Clears error handling state and branches execution directly to the specified target line number.
      - Traps `RESUME without error` (Error 20) when `RESUME` is executed outside an active error handler.
    - **User Error Generation (`ERROR`)**:
      - `ERROR <expr>` (`TOK_ERROR` `0x00A7`): Simulates or raises runtime error code $1 \le \text{code} \le 255$, routing to the active error handler or terminating with standard error message.
    - **Computed Branching (`ON <expr> GOTO/GOSUB`)**:
      - `ON <expr> GOTO <line1>, <line2>, ...`: Jumps to the $n$-th line number in the list based on 1-based integer expression value; falls through if index is out of list bounds.
      - `ON <expr> GOSUB <line1>, <line2>, ...`: Calls the $n$-th line number subroutine in the list, pushing return line and statement position to the GOSUB call stack.
    - **Target Error Handling Verification Suite (`/BASIC/ERR.BAS`, `/ERR.BAS`)**: Comprehensive verification test suite covering 6 test sections: division by zero trap with `ERR`/`ERL` verification and `RESUME NEXT`; statement retry via `RESUME 0` repairing divisor; custom error code generation with `ERROR 55` and `RESUME <line>`; multi-branch computed `ON...GOTO`; multi-branch computed `ON...GOSUB`; and multi-statement line recovery via `RESUME NEXT`. Verified 100% passed on target Book8088 emulator.
  - **Phase 10: Event Trapping (`ON TIMER(n) GOSUB`, `TIMER ON/OFF/STOP`, `ON KEY(n) GOSUB`, `KEY(n) ON/OFF/STOP`, `KEY ON/OFF`, `KEY LIST`, `KEY n, "string"`, `RETURN <linenum>`)**:
    - **Timer Event Trapping Engine**:
      - `ON TIMER(n) GOSUB <linenum>`: Configures a recurring timer trap handler triggered every $n$ seconds ($1 \le n \le 86400$).
      - `TIMER ON`: Enables timer event polling at statement boundaries.
      - `TIMER STOP`: Suspends event handling while latching and preserving pending timer ticks so they fire immediately upon the next `TIMER ON`.
      - `TIMER OFF`: Completely disables timer trapping and discards any pending timer ticks.
    - **Keyboard Event Trapping & Softkeys**:
      - `ON KEY(n) GOSUB <linenum>`: Configures key event trapping for function keys 1..10 (F1..F10) and cursor keys 11..14 (Up, Left, Right, Down).
      - `KEY(n) ON`, `KEY(n) STOP`, `KEY(n) OFF`: Controls trapping state per key trap index with event queuing and latching.
      - `KEY ON`: Displays 10 function key softkey prompts on screen line 24.
      - `KEY OFF`: Clears and blanks line 24 prompt row.
      - `KEY LIST`: Prints current definitions of all 10 function keys to the console.
      - `KEY n, "string"`: Customizes function key macro string (keys 1..10, up to 15 characters).
    - **Event Polling & Non-Local Return**:
      - `basic_poll_events()`: Evaluates timer ticks and keyboard FIFO traps at statement boundaries, simulating an asynchronous `GOSUB` to the handler while preserving execution state.
      - `RETURN [linenum]`: Extended `RETURN` to accept an optional target line number (`RETURN <linenum>`), popping the GOSUB return stack and transferring control directly to the target line.
    - **Tokenizer & Parser Refinements**:
      - Fixed keyword tokenization boundary checks (`basic_tokenize`) to ensure keywords are not matched when preceded by an alphanumeric identifier character (resolving collision with variables like `TWAIT` vs `WAIT`).
      - Extended variable identifier parser (`basic_parse_var_name`) to support underscores (`_`) in variable names.
    - **Memory Layout & 64 KB Segment Confinement**:
      - Adjusted BSS symbol tables and runtime arrays (`BASIC_MAX_VARS = 48`, `BASIC_MAX_STR_LEN = 64`, `BASIC_NUM_TEMP_STRS = 6`, `BASIC_MAX_ARRAYS = 16`, `BASIC_MAX_GOSUB = 16`, `BASIC_MAX_FOR_NEST = 8`, `BASIC_MAX_WHILE_NEST = 8`) to keep total executable footprint at 62,008 bytes (`0xF238`), ensuring full flat 64 KB segment safety with 3.5 KB stack headroom below `0xFEFE`.
    - **Target Event Trapping Verification Suite (`/BASIC/EVENT.BAS`, `/EVENT.BAS`)**: Comprehensive verification suite covering softkey management (`KEY ON/OFF`, `KEY 1, "..."`), key trap syntax & validation (`ON KEY(1) GOSUB`, `KEY(0)` out of bounds error trapping), `RETURN <linenum>` redirection, recurring `TIMER ON` event delivery, `TIMER STOP` event buffering and pending firing upon `TIMER ON`, and `TIMER OFF` deactivation. ## Revision 0.2 (2026-11-14)

- **System Call Interface & Public API (`include/hobbyos.h`, `kernel/syscall.c`, `kernel/entry.asm`)**:
  - Implemented `INT 0x21` system call handler switching safely to the kernel data/stack segment (`0x1000`) during dispatch.
  - Added public Open Watcom `#pragma aux` wrappers for user-space and kernel callers: `os_exit`, `os_putc`, `os_puts`, `os_getc`, `os_kbhit`, `os_cls`, `os_set_cursor`, `os_get_cursor`, `os_get_args`, `os_file_read`, `os_file_write`, `os_file_size`, `os_file_delete`, `os_dir_entry`, and `os_exec`.
- **Screen & Keyboard Drivers (`kernel/console.c`, `kernel/entry.asm`)**:
  - Added direct CGA 80x25 text-mode screen driver (`0xB800:0000`) with hardware CRTC cursor updates (`0x3D4`/`0x3D5`), BIOS Data Area cursor synchronization (`0x0040:0x0050`), colors, newline/tab/backspace handling, and scrolling.
  - Added PC/XT keyboard driver via BIOS `int 0x16` (`AH=00h`/`01h`) and line editing (`con_getline`).
  - Dropped `COM1` serial console output/input usage while retaining `serial_init()` for future serial mouse support.
- **Kernel FAT16 Driver (`kernel/fat16.c`)**:
  - Implemented full FAT16 volume support via BIOS `int 0x13` (`AH=02h`/`03h`): BPB parsing, directory enumeration, file size query, file reading (`fat16_read_file`), file creation/overwriting with dual-FAT cluster allocation (`fat16_write_file`), file deletion (`fat16_delete_file`), and multi-segment executable loading (`fat16_load_executable`).
- **Executable Loader, User-Space Runtime & Interactive Shell (`user/crt0.asm`, `user/hello.c`, `kernel/main.c`)**:
  - Added `exec_program` and `_proc_exec_far` / `_proc_exit_usermode` to load flat 16-bit binaries into user segment `0x2000:0000`, pass command-line arguments at `0x2000:0xFF00`, and restore kernel state upon `SYS_EXIT`.
  - Added user-space runtime (`user/crt0.asm`) and sample user program (`HELLO.BIN`) that tests console output, FAT16 file write/read (`NOTES.TXT`), and directory listing via `INT 0x21`.
  - Added interactive kernel shell (`hobbyOS> `) supporting `help`, `ls`/`dir`, `cat`, `write`, `rm`, `run`, and `cls`.

## Revision 0.1 (2026-11-14)

- **FAT16 Bootloader (`boot/boot.asm`)**:
  - Replaced raw hardcoded sector reads with a real FAT16 Volume Boot Record (VBR) including a standard BIOS Parameter Block (BPB) and Extended BPB (`4` heads, `17` sectors/track, `512` bytes/sector, `4` sectors/cluster).
  - Enforced strict 8086/8088 instruction set compatibility (`CPU 8086`).
  - Dynamically computes FAT, Root Directory, and Data region LBAs from the BPB.
  - Searches the FAT16 Root Directory for `KERNEL.BIN`, follows its FAT16 cluster chain, converts LBAs to CHS for BIOS `int 0x13` (`AH=0x02`), loads the kernel into `0x1000:0x0000` (with 64 KB segment wrap handling), and jumps to it.
  - Added BIOS `int 0x10` status indicators: `B` (boot started), `K` (kernel loaded), `N` (`KERNEL.BIN` not found), and `E` (disk I/O error).
- **FAT16 Disk Image Pipeline (`tools/fat16.py` & `Makefile`)**:
  - Formatted `book8088/disk.img` as a standard FAT16 volume (`HOBBYOS`) using `mkfs.fat`.
  - Added `tools/fat16.py` to install the compiled VBR boot code while preserving the BPB and copy `build/kernel.bin` into the FAT16 root directory as `KERNEL.BIN`.
